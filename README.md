# 好職雷達

網站網址：[https://good-job-radar.onrender.com/](https://good-job-radar.onrender.com/)

好職雷達協助你搜尋台灣就業通的公開職缺，依照自己的薪資、休假和產業偏好查看職缺評分。

## 操作說明

1. 開啟網站，瀏覽職缺清單；可搜尋關鍵字，或使用地點、工作類型和排序條件縮小範圍。
2. 按 **「調整我的條件」** 設定最低月薪、周休二日偏好和產業，再儲存即可依條件重新評分。
3. 職缺卡片會顯示 1–10 分和評分原因。尚未設定偏好時，職缺顯示「未設定」。
4. 按愛心收藏職缺，並可更新求職狀態，例如「想投遞」或「已投遞」。
5. 按 **「加入職缺」** 可貼上職缺網址或文字，將職缺加入清單。

收藏、求職狀態、手動加入的職缺和偏好設定保存在目前瀏覽器中；清除瀏覽器資料或換裝置後不會自動同步。

## 評分與資料

評分會平均計算已設定條件的符合程度。薪資、休假或產業資訊若未公開或無法判斷，會以中間分數計算並標示資料不足。休假方式和產業可能由職缺文字推估，建議查看原始職缺確認詳細條件。

公開職缺資料來自[台灣就業通職缺清單](https://data.gov.tw/dataset/44062)，網站會定期同步，並提供原始職缺連結供進一步查閱。
